## 服务器租赁前，先分清三种租法

服务器租赁的钱花在哪种形态上，取决于负载跑多久、吃 CPU 还是吃 GPU。市面上主要有三条路：

**独立服务器（裸金属）**：整台物理机归你，硬件不共享，自己装系统、自己搞虚拟化。适合 7×24 小时长期跑、对性能和隔离性有要求的业务——游戏服务器、数据库、高密度虚拟化宿主机都属于这类。计费基本是月付。

**VPS（云主机）**：一台物理机切成多份。Sharktech 的 SmartVPS 月付 $7.95 起，包含 2 vCPU、4GB 内存、40GiB NVMe 和 4TB 流量，年付直接五折。轻量业务、测试环境选这条最省。

**GPU 云 / 算力租赁**：按小时计费，用几小时付几小时。阿里云的 GPU 云服务器覆盖 V100、A100 等型号，支持按量付费；国内不少算力平台的消费级卡（如 RTX 4090、5090）每小时价格在几块钱人民币量级。短期训练、推理实验，这种形态几乎必然比包月独服划算；但一个任务 7×24 跑满一个月，小时账单会远超一台独服的月费。

一句话的决策规则：**短期、弹性、吃 GPU → 按小时租云算力；长期、稳定、吃 CPU 和网络 → 月付独服；轻负载 → VPS。** 大多数搜「服务器租赁」的人真正要的是第二种。

## 10Gbps 带宽的真实含义

这里有一个几乎没人讲清楚的细节：Sharktech 宣传的「每台标配 10Gbps」，指的是**端口连接速率**，实际吞吐取决于流量路径和工作负载。官网原文写得很明白："Port capacity describes the connection speed; actual throughput depends on the traffic path and workload."

也就是说，你付钱买到的是一根 10G 的管子，不代表任何时候都能跑满 10G。对大多数业务这无所谓——300TB/月的流量配额，在 10Gbps 端口下持续满速传输大约 67 小时（不到三天）就能跑完，说明配额本身留了很大余量。但如果你的场景是视频分发、大文件下载站，需要真正跑满端口，要么确认流量路径质量，要么直接考虑不限流量的 10Gbps 配置——Sharktech 官方促销页曾放出不限流量的 E3-1270v2 档，阿姆斯特丹节点折后 $269/月，这类配置是否仍有库存、以官网独服列表当前显示为准。
